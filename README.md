# Saucedemo_TestingUsingPOM
**Project Overview**

This project contains UI automation tests for the SauceDemo web application using Playwright with TypeScript.

The main goal of this project is to practise web UI automation, validate essential e-commerce workflows, and apply the Page Object Model (POM) design pattern to create reusable and maintainable test code.

**Technologies Used**
1.Playwright – Browser automation and end-to-end testing
2.TypeScript – Programming language for writing automated tests
3.Node.js and npm – Runtime environment and package management
4.Page Object Model (POM) – Design pattern for organizing page locators and actions
5.Git and GitHub – Version control and project hosting

**Application Under Test**
1. Website: https://www.saucedemo.com/
2. Application type: E-commerce demo website
3. Testing type: UI automation and functional testing

**Test Scenarios**
The project covers the following scenarios:
1. Login with valid credentials
2. Verify successful login and navigation to the inventory page
3. Open a product details page.
4. Arrange the products in low to high price
5. Open Menu options
6. Choose a option
7. Add a product to the cart directly from the inventory page
8. Verify that a product has been added to the cart
9. Remove a product from the cart
10. Verify that a product has been removed successfully

Additional scenarios may be added as the project develops.
